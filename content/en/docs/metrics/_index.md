These metrics help you assess your current delivery performance and track improvement
over time. Start with the metrics most relevant to your current phase.

## Key Metrics

| Metric | What It Measures |
|--------|------------------|
| [Integration Frequency](integration-frequency/) | How often code is integrated to trunk |
| [Build Duration](build-duration/) | Time from commit to artifact creation |
| [Development Cycle Time](development-cycle-time/) | Time from starting work to delivery |
| [Lead Time](lead-time/) | Time from request to delivery |
| [Change Fail Rate](change-fail-rate/) | Percentage of changes requiring remediation |
| [Mean Time to Repair](mean-time-to-repair/) | Time to restore service after failure |
| [Release Frequency](release-frequency/) | How often releases reach production |
| [Work in Progress](work-in-progress/) | Amount of started but unfinished work |
