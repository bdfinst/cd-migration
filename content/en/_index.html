A phased guide for teams moving from quarterly releases to deploying every change.

{{< /blocks/cover >}} {{% blocks/lead color="primary" %}} ## Your Migration Journey Most teams don't leap to continuous deployment overnight. This guide organizes proven practices from [MinimumCD.org](https://minimumcd.org) and the [Dojo Consortium](https://dojoconsortium.org) into five progressive phases — from assessing where you are today to deploying every commit with confidence. {{% /blocks/lead %}} {{< blocks/section color="white" >}} {{% blocks/feature icon="fa-magnifying-glass" title="Phase 0: Assess" url="/docs/assess/" %}} Understand where you are. Map your value stream, establish baseline metrics, and identify constraints. {{% /blocks/feature %}} {{% blocks/feature icon="fa-layer-group" title="Phase 1: Foundations" url="/docs/foundations/" %}} Build the essential practices: trunk-based development, testing fundamentals, small work decomposition. {{% /blocks/feature %}} {{% blocks/feature icon="fa-timeline" title="Phase 2: Pipeline" url="/docs/pipeline/" %}} Create the automated path to production: a single, deterministic pipeline that deploys immutable artifacts. {{% /blocks/feature %}} {{< /blocks/section >}} {{< blocks/section color="light" >}} {{% blocks/feature icon="fa-gauge-high" title="Phase 3: Optimize" url="/docs/optimize/" %}} Improve flow with smaller batches, feature flags, WIP limits, and metrics-driven improvement. {{% /blocks/feature %}} {{% blocks/feature icon="fa-rocket" title="Phase 4: Continuous Deployment" url="/docs/continuous-deployment/" %}} Deploy every change on demand with progressive rollout strategies and full confidence. {{% /blocks/feature %}} {{% blocks/feature icon="fa-book" title="Reference" url="/docs/reference/" %}} Glossary, metrics definitions, testing guides, and additional resources. {{% /blocks/feature %}} {{< /blocks/section >}}
