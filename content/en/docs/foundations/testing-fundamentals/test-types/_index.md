Definitions for the test types used throughout this site. Each page covers what the type is, when it runs in the [pipeline]({{< relref "/docs/reference/glossary#pipeline" >}}), what it asserts on, and what it does not.

The list isn't exhaustive and the boundaries between types aren't crisp in every codebase. Use these definitions as shared vocabulary for the rest of the testing section, especially [Applied Testing Strategies]({{< relref "/docs/foundations/testing-fundamentals/applied-testing-strategies" >}}) and [Testing Antipatterns]({{< relref "/docs/foundations/testing-fundamentals/antipatterns" >}}).
