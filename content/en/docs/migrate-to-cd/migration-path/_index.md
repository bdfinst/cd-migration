{{% pageinfo %}}
The Migration Path is a structured, phased journey from wherever you are today to continuous
deployment. Each phase builds on the previous one, so work through them in order.
{{% /pageinfo %}}

## The Phases

| Phase | Focus | Key Question |
|-------|-------|-------------|
| [0 - Assess](assess/) | Understand your current state | How far are we from CD? |
| [1 - Foundations](foundations/) | Daily integration, testing, small batches | Can we integrate safely every day? |
| [2 - Pipeline](pipeline/) | Automated path from commit to production | Can we deploy any commit automatically? |
| [3 - Optimize](optimize/) | Reduce batch size, limit WIP, measure | Can we deliver small changes quickly? |
| [4 - Deliver on Demand](continuous-deployment/) | Deploy any change when the business needs it | Can we deliver any change to production when needed? |

## Where to Start

If you are unsure where to begin, start with [Phase 0: Assess](assess/) to understand your
current state and identify the constraints holding you back.
