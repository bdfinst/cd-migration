This guide organizes practices from [MinimumCD.org](https://minimumcd.org) and the
[Dojo Consortium](https://dojoconsortium.org) into a phased migration journey.
Each phase builds on the previous one — start where you are, progress at your own pace.
{{% /pageinfo %}}

## The Five Phases

| Phase | Name | Goal | Key Question |
|-------|------|------|--------------|
| 0 | [Assess](assess/) | Understand where you are | "How far are we from CD?" |
| 1 | [Foundations](foundations/) | Daily integration, testing, small work | "Can we integrate safely every day?" |
| 2 | [Pipeline](pipeline/) | Automated path to production | "Can we deploy any commit automatically?" |
| 3 | [Optimize](optimize/) | Improve flow, reduce batch size | "Can we deliver small changes quickly?" |
| 4 | [Continuous Deployment](continuous-deployment/) | Deploy on demand | "Can we deploy every change?" |

## How to Use This Guide

1. **Start with Phase 0** to assess your current state and identify your biggest constraints.
2. **Work through each phase sequentially.** Each phase builds on the practices established in the previous phase.
3. **Use the reference section** for detailed definitions, metrics, and testing patterns.
4. **Don't skip phases.** Teams that jump to pipeline automation without solid foundations tend to automate broken processes.
